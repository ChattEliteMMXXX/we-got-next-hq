WE GOT NEXT: MMXXX HQ V9 — GitHub Pages/PWA

1. Sign in to GitHub and create a PUBLIC repository, e.g. we-got-next-hq. Do not add a README during creation.
2. Upload ALL files in this folder to the ROOT of the repository (keep icons inside the icons folder). Upload the extracted files, not the ZIP.
3. Commit the files to the main branch.
4. Repository > Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. GitHub will show the published website URL on the Pages settings screen, generally https://YOUR-USERNAME.github.io/we-got-next-hq/.
6. Open it in Chrome on Windows > Chrome menu > Cast, save and share > Install page as app (menu wording varies). On Samsung Chrome > menu > Add to Home screen > Install.

Public safety: HQ files and embedded outbound URLs are public on GitHub Pages. No secrets, roster databases, tokens, or private Apps Script source should be placed in this repo. Linked Google apps still require their own authorization. Offline mode covers only the HQ shell; linked Google apps need internet.

Practice Lab is linked to the V18.13 deployment URL already supplied; Practice Lab files are NOT included or modified. The PWA has not been tested on an actual deployed domain and requires HTTPS (provided by GitHub Pages) to activate the service worker.
